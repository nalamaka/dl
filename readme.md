# 深度学习实验仓库

本仓库汇总了一组基于 PyTorch 实现的深度学习课程实验，包含图像分类、自然语言生成、神经机器翻译和语义分割等任务。各实验相互独立，具体的环境配置、数据准备和运行命令请参阅对应目录中的 `README.md`。

## 仓库组成

| 路径 | 内容 |
| --- | --- |
| `src/` | 各实验的源码、配置、训练与评估脚本 |
| `data/` | 本地数据集目录，不纳入 Git 版本控制 |
| `checkpoint/` | 本地模型检查点目录，不纳入 Git 版本控制 |
| `log/` | 本地训练日志目录，不纳入 Git 版本控制 |

### 实验列表

| 实验 | 主题 | 主要方法 |
| --- | --- | --- |
| `exp1` | MNIST 手写数字识别 | 卷积神经网络（CNN） |
| `exp2` | CIFAR-10 图像分类 | Vision Transformer（ViT） |
| `exp3` | 中文古诗生成 | 字符级因果 Transformer、格式与押韵约束 |
| `exp4` | 中英神经机器翻译 | Transformer Seq2Seq、BLEU-4 评估 |
| `exp6` | CamVid 街景语义分割 | SegNet、PA/MPA/mIoU/fwIoU 评估 |

各实验的主要入口为 `src/<实验编号>/main.py`；目录中如有 `README.md`，请优先按其中的环境、数据和运行说明操作。

训练生成的模型权重、检查点、日志、数据集和可视化产物仅保存在本地，并已通过 `.gitignore` 排除，不会随正常的 Git 提交上传到远程仓库。
